# app

올해 우리는의 잇기 웹 프로토타입이에요. 친구 초대부터 사진 선택, 시연용 분석, 내 사진 공개, 같은 순간 확인, 공동 회고까지 휴대폰 브라우저에서 체험할 수 있어요.

Node.js 22.13 이상 또는 24 LTS를 사용해요.

```bash
cd app
npm ci
npm run web
```

터미널에 표시되는 주소로 열어요. 정적 웹 빌드는 `npm run build:web`을 실행하면 `app/dist/`에 나와요. 이 폴더를 로컬 정적 서버에서 열 수 있어요.

## 확인할 수 있는 흐름

1. 홈에서 잇기를 누르고 예시 방에 들어가요. 예시 사진 10장 이상을 골라 제출해요.
2. 친구 제출과 분석은 시연용 응답으로 진행돼요. 내 사진 공개를 승인하고 서로 찍은 사진을 확인해요.
3. 같은 순간이면 공동 회고가 열려요. 다른 순간이면 사진을 다시 고를 수 있어요.
4. 회고를 한 번 만들면 같은 페이지가 열린 동안 홈의 내 회고에서 다시 볼 수 있어요.

`linkingDemo.js`가 방, 후보와 회고에 대한 예시 응답을 제공해요. 실제 초대 링크, 사진첩 접근, 서버 분석과 저장은 연결 전이에요. 시연 사진은 생성된 이미지이며 실제 개인 사진은 업로드되지 않아요.

정식 앱에서는 사건 묶기, 임베딩과 개인 후보 고르기를 기기에서 처리해요. 기기용 모델 파일은 `ml/on-device/`를 참고해요.
