# 잇기 MegaLoc 후보의 LightGlue 재정렬

MegaLoc 상위 5개를 ALIKED와 LightGlue의 일치점 수로 다시 정렬해 ITLP 교차 시간대 평가에서 비교했어요. 질의 100장, 검색 대상 1,233장이에요.

- 규칙 A: 일치점이 많은 순서
- 규칙 B: 최다 일치점이 20개 미만이면 MegaLoc 순서 유지
- 규칙은 전체 결과를 보기 전에 정했어요. 로봇 팔 영역의 특징점은 빼요. 인물 제거는 정답 마스크를 쓴 조건이에요.

| 조건 | MegaLoc R@1 | 규칙 A (얻음/잃음) | 규칙 B (얻음/잃음) | 상위 5개 한계 |
| --- | ---: | ---: | ---: | ---: |
| C 사람 추가 없음 | 83 | 87 (8/4) | 87 (8/4) | 98 |
| S 평균 17.5% 가림 | 73 | 82 (11/2) | 81 (10/2) | 95 |
| S 인물 제거 | 73 | 81 (10/2) | 80 (9/2) | 95 |
| L 평균 49.5% 가림 | 60 | 65 (13/8) | 68 (11/3) | 81 |
| L 인물 제거 | 60 | 65 (11/6) | 65 (9/4) | 81 |

회전 없음의 값이에요. 네 방향 회전은 A의 S가 81, L이 64였고 나머지는 같았어요. ITLP 사진은 모두 바로 서 있어 회전의 이득을 볼 수 없는 데이터예요.

전체 실행은 맥미니 M4에서 448초, 질의당 평균 약 0.9초였어요. 후보 5개를 네 방향으로 매칭한 시간이에요. 스왑은 늘지 않았어요.

## 해석과 한계

- 모든 조건에서 늘었지만 쌍별 부호 검정에서 p < 0.05인 것은 S의 일부뿐이에요(A 0.022, B 0.039, 인물 제거 A 0.039). 여러 조건을 함께 봤고 보정하지 않았어요. L의 B는 0.057이에요.
- 건물 한 곳, 합성 인물 3명의 결과예요. 마주 보고 찍은 사진은 들어 있지 않아요.
- 일치점이 적다고 후보에서 빼면 안 돼요.

실행에는 `../2026-11-25-linking-occlusion-train-data/`의 코드와 LightGlue(`cvg/LightGlue`)가 필요해요. 행별 일치점은 `report.json`에 있어요.
