# 잇기 인물 가림 학습 데이터

MegaLoc LoRA 시범 학습에 쓸 합성 데이터의 생성 코드, 검증 코드와 목록이에요. 합성 이미지는 [data/occlusion-train-v2](../../../data/occlusion-train-v2/README.md)에 있어요. 인물 컷아웃은 올리지 않고 로컬 `data/private/`에 둬요.

## v1을 늘린 이유

| 항목 | v1 | 이번 데이터 | 개발 계획의 첫 시작 규모 |
| --- | ---: | ---: | ---: |
| 학습 배경 | 14 | 51 | 200 |
| 학습 인물 | 6 | 13 | 100 |
| 학습 쌍 | 28 | 306 | |
| 가림 비율 | 18% 한 값 | 10~25%, 25~40%, 40~60% | L 목표 40~70% |
| 위치 | 가로 60% 한 값 | 무작위 | |

v1에는 평가 대상인 큰 가림이 없었어요. 새 데이터는 구간마다 배경당 두 쌍이에요. 큰 가림에서 한 명만 놓으면 인물이 대부분 잘리는 경우 두 명을 나란히 놓았어요(111쌍 중 17쌍).

배경과 인물은 학습과 합성 내부 확인에서 겹치지 않아요. 내부 확인은 배경 6장, 인물 3명, 31쌍이에요.

## 다시 만들기

Pillow가 필요해요.

```bash
python3 build_occlusion_train.py --private <data/private 경로> --out <출력 폴더>
python3 verify_occlusion_train.py <출력 폴더>
```

`--private` 폴더에는 `backgrounds.csv`의 배경이 `occlusion-v2/` 아래에, `donors.csv`의 컷아웃이 적힌 경로에 있어야 해요. 같은 입력으로 두 번 만들었을 때 모든 PNG의 해시가 같았어요.

## 확인한 것

크기, 이진 마스크, 마스크 픽셀 수, 가림 구간, 마스크 밖 원본 일치, 분할 겹침을 337쌍 모두 검사했고 오류는 없었어요. 합성본은 일부만 눈으로 확인했어요.

## 한계

- 배경 51장과 인물 13명은 코드와 개선 신호를 보는 시범 학습용이에요. 본 학습에는 부족해요. 쌍 수를 늘려도 독립적인 장소 수는 늘지 않아요.
- 인물별 사용 횟수가 8~62회로 고르지 않아요. 큰 가림은 상반신 컷아웃 몇 개에 몰려요.
- 빛, 크기와 가구 앞뒤 관계가 어색한 컷이 있고 일부 인물은 윗부분이 잘린 채 보여요.
- 실제 사진에서 매칭이 나아지는지는 확인하지 않았어요.
- 인물 원본은 CC BY 2.0이지만 인물의 동의는 확인되지 않았어요.

## 파일

- `pairs.csv`, `splits.csv`: 쌍과 분할 목록
- `backgrounds.csv`, `donors.csv`: 출처, 저작자와 라이선스
- `v1/`: 앞서 만든 40쌍의 생성 코드와 목록. 실행에는 저장소에 없는 선별 설정과 컷아웃이 필요해요.

## 시범 학습 결과

맥미니 M4 16GB, MPS, 322px, 배치 2, 마지막 4개 블록 qkv LoRA(rank 8, 학습 파라미터 98,304개), 5 에폭 765스텝이에요. 275초가 걸렸고 MPS 최대 2,072MB, 스왑 증가는 0MB였어요. 원본 교사 특징과의 코사인 유사도예요. E1의 인물 마스크는 합성할 때 만든 정답 마스크예요.

| 합성 내부 확인 | 장수 | E0 원본 | E1 마스킹 | E3 LoRA |
| --- | ---: | ---: | ---: | ---: |
| 작은 가림 | 12 | 0.796 | 0.857 | 0.852 |
| 중간 가림 | 10 | 0.667 | 0.737 | 0.736 |
| 큰 가림 | 9 | 0.543 | 0.607 | 0.610 |
| 깨끗한 사진 | 6 | 1.000 | 1.000 | 0.988 |

**검색은 세 방식 모두 31/31 성공이라 이 데이터로는 검색 개선을 판단할 수 없어요.** 질의가 정답과 같은 사진에 사람만 얹은 것이고 검색 대상이 57장뿐이에요. LoRA는 유사도에서 마스킹과 비슷했고 깨끗한 사진의 표현을 조금 바꿨어요. 모델 교체 근거로 쓰지 않아요. 사각형 대조군(E2)은 실행하지 않았어요.

전체 값은 `report-e3.json`에 있어요. LoRA 가중치는 저장소에 올리지 않아요.

## 교차 시간대 검색 평가 (ITLP)

`build_hard_eval.py`로 만든 목록에서 `eval_hard.py`로 쟀어요. 황혼 질의 100장을 야간 1,233장에서 찾고, 정답은 같은 층에서 2m, 30도 안이며 시점이 0.5m 또는 10도 이상 달라요. 정답 쌍 10개를 눈으로 확인했고 모두 같은 장소로 보였어요. 사람은 학습에 쓰지 않은 3명을 합성했어요. ITLP Campus Indoor는 CC BY 4.0이고 이미지는 저장소에 올리지 않아요.

| 조건 | E0 원본 R@1 / R@5 | E3 LoRA R@1 / R@5 |
| --- | ---: | ---: |
| C 사람을 추가하지 않음 | 83 / 98 | 82 / 98 |
| S 평균 17.5% 가림 | 73 / 95 | 76 / 95 |
| L 평균 49.5% 가림 | 60 / 81 | 61 / 84 |
| S 인물 마스킹 | 79 / 95 | 79 / 95 |
| L 인물 마스킹 | 58 / 82 | 62 / 83 |
| S와 같은 면적 사각형 | 80 / 94 | 78 / 93 |
| L과 같은 면적 사각형 | 51 / 73 | 52 / 77 |

큰 가림에서 원본이 찾던 83장 중 29장을 놓쳤고 6장을 새로 찾았어요. LoRA의 차이는 1~3장으로 작아 개선이라고 보지 않아요. 건물 한 곳과 합성 인물의 결과라 본 학습 여부는 직접 촬영으로 정해요. MegaLoc 학습 데이터와의 겹침은 확인하지 않았고, 마스킹은 정답 마스크를 쓴 조건이에요. C에도 실제 사람이 찍힌 사진이 있어요. 전체 값은 `report-hard-eval.json`에 있어요.
