# 잇기 인물 가림 학습 데이터

MegaLoc LoRA 시범 학습에 쓸 합성 데이터의 생성 코드, 검증 코드와 목록이에요. 공개 저장소라 이미지와 컷아웃은 올리지 않고 `data/private/`에 해당하는 로컬 폴더에 둬요.

## v1을 늘린 이유

| 항목 | v1 | 이번 데이터 | 개발 계획의 첫 시작 규모 |
| --- | ---: | ---: | ---: |
| 학습 배경 | 14 | 51 | 200 |
| 학습 인물 | 6 | 13 | 100 |
| 학습 쌍 | 28 | 306 | |
| 가림 비율 | 18% 한 값 | 10~25%, 25~40%, 40~60% | L 목표 40~70% |
| 위치 | 가로 60% 한 값 | 무작위 | |

v1에는 평가 대상인 큰 가림이 없었어요. 새 데이터는 구간마다 배경당 두 쌍이에요. 큰 가림에서 한 명만 놓으면 인물이 대부분 잘리는 경우 두 명을 나란히 놓았어요(111쌍 중 17쌍).

배경과 인물은 학습과 합성 내부 확인에서 겹치지 않아요. 내부 확인은 배경 6장, 인물 3명, 31쌍이에요.

## 다시 만들기

Pillow가 필요해요.

```bash
python3 build_occlusion_train.py --private <data/private 경로> --out <출력 폴더>
python3 verify_occlusion_train.py <출력 폴더>
```

`--private` 폴더에는 `backgrounds.csv`의 배경이 `occlusion-v2/` 아래에, `donors.csv`의 컷아웃이 적힌 경로에 있어야 해요. 같은 입력으로 두 번 만들었을 때 모든 PNG의 해시가 같았어요.

## 확인한 것

크기, 이진 마스크, 마스크 픽셀 수, 가림 구간, 마스크 밖 원본 일치, 분할 겹침을 337쌍 모두 검사했고 오류는 없었어요. 합성본은 일부만 눈으로 확인했어요.

## 한계

- 배경 51장과 인물 13명은 코드와 개선 신호를 보는 시범 학습용이에요. 본 학습에는 부족해요. 쌍 수를 늘려도 독립적인 장소 수는 늘지 않아요.
- 인물별 사용 횟수가 8~62회로 고르지 않아요. 큰 가림은 상반신 컷아웃 몇 개에 몰려요.
- 빛, 크기와 가구 앞뒤 관계가 어색한 컷이 있고 일부 인물은 윗부분이 잘린 채 보여요.
- 실제 사진에서 매칭이 나아지는지는 확인하지 않았어요.
- 인물 원본은 CC BY 2.0이지만 인물의 동의는 확인되지 않았어요.
