# ml

사진을 고르고 잇는 모델과 실험 코드예요.

| 폴더 | 내용 |
| --- | --- |
| `picking/` | 고르기: 사건별 대표 사진 추천, 중복 정리 |
| `linking/` | 잇기: 공동 사건 후보 찾기, 장면 유사도, 사진 짝짓기 |
| `on-device/` | MobileCLIP2 같은 모델을 기기용(Core ML, LiteRT)으로 변환하고 속도 측정 |
| `experiments/` | 메타데이터 기준선과 CV를 더한 결과 비교 기록 |

모델 가중치 파일(`.pt`, `.onnx`, `.tflite` 등)은 커밋하지 않아요. 받는 방법을 README에 적어요.
