# data

데이터 형식과 정답 표시 방법을 두는 곳이에요. **사진 원본은 이 저장소에 올리지 않아요.**

| 폴더 | 내용 |
| --- | --- |
| `schema/` | 촬영 정보, 사건, 사진 쌍, 사용자 선택 기록의 형식 정의 |
| `labeling/` | 같은 사건, 같은 사진 짝을 사람이 표시하는 가이드 |

- 동의받은 사진은 각자 컴퓨터의 `data/local/`에 두세요. 이 폴더는 `.gitignore`로 커밋되지 않아요.
- 연구용 데이터 이용 동의를 받은 사진만 실험에 써요.
- 학습과 평가는 친구 무리 단위로 나눠요.
