# 올해 우리는

친구들의 사진첩에 흩어진 같은 순간을 AI로 찾아 연결하고, 함께 한 해를 돌아보는 연말 회고 앱이에요.

## 폴더 구조

| 폴더 | 무엇을 두나요 | 주로 맡는 파트 |
| --- | --- | --- |
| `app/` | 모바일 앱 화면과 기기 안에서 도는 코드 | 앱 개발 |
| `server/` | 방 만들기, 친구 초대, 공유 승인 API | 앱 개발 |
| `worker/` | 승인한 사진으로 사진 짝짓기와 회고 구성 | 잇기, 고르기 |
| `ml/picking/` | 고르기: 사건별 대표 사진 추천 | 고르기 |
| `ml/linking/` | 잇기: 서로의 사진첩에서 같은 순간 찾기 | 잇기 |
| `ml/on-device/` | 기기용 모델 변환과 속도 측정 | 앱 개발, 고르기 |
| `ml/experiments/` | 기준선과 모델을 비교한 실험 기록 | 데이터·검증 |
| `data/` | 데이터 형식, 정답 표시 가이드 (사진 원본은 올리지 않아요) | 데이터·검증 |
| `docs/` | 설계 문서, 로컬 실행 방법 | 공통 |

각 폴더의 `README.md`에 자세한 설명이 있어요.

## 꼭 지켜요

- 실제 개인 사진, 위치 정보, API 키는 커밋하지 않아요. 이 저장소는 공개 저장소예요.
- 작업은 `develop`에서 브랜치를 만들고 PR로 합쳐요. 브랜치 이름에는 Jira 이슈 키를 넣어요. 예: `feature/KAN-12-recap-preview`
- 자세한 협업 방식은 팀 노션의 「협업 방식 공유」를 봐요.
